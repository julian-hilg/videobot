# Bundled stories

`seed_stories.json` is the starter set a fresh videobot database is filled with. It is **not** covered
by the MIT licence of the code. Every entry lists its own source, URL and licence:

- Wikipedia article introductions: CC BY-SA 4.0, by Wikipedia contributors.
  https://creativecommons.org/licenses/by-sa/4.0/
- Aesop's fables (tr. George Fyler Townsend, via Project Gutenberg eBook #21): public domain.

Rebuild it with `uv run python scripts/build_seed.py`.
